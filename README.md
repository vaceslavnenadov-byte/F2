# Пустошь 2241 — Арройо (3D)

Фанатское переосмысление Fallout 2 в полном 3D с современным рендером. Сейчас это вертикальный срез: стартовая локация Арройо с ключевыми механиками оригинала.
Ассеты оригинала не используются: вся графика процедурная (модели, текстуры, рельеф).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

## Что уже есть

- **Мир**: процедурная пустыня 160×160 м со столовыми горами, деревня Арройо (хижины, частокол с тотемами, костёр, загон с двухголовыми браминами, огород шамана), Храм Испытаний, гнездо гекконов в каньоне.
- **Графика**: PBR-материалы, атмосферное небо, окружение для отражений, мягкие тени, экспоненциальный туман, ACES-тонмаппинг, bloom, цветокоррекция с виньеткой и плёночным зерном, трава на ветру, частицы огня, дыма и пыли, динамический свет факелов.
- **Персонаж**: создание героя по S.P.E.C.I.A.L. (40 очков), три отмеченных навыка, производные характеристики и уровни по формулам, близким к оригиналу.
- **Пошаговый бой**: очерёдность по Восприятию, очки действия (1 ОД за клетку), шанс попадания по навыку и КБ цели, штраф за дистанцию, критические удары от Удачи, предпросмотр пути и стоимости, ИИ врагов (подход, атака, бегство раненых).
- **Диалоги** с ветвлением, проверками навыков (`[Красноречие 45]`) и особыми репликами при Интеллекте ≤ 3.
- **Задания**: «Гнездо в каньоне» (Старейшина) и «Пропавший Дымок» (Нагор; пёс становится спутником).
- **Интерфейс** в стиле Fallout 2: журнал на ЭЛТ-экране, ОЗ/КБ, индикатор ОД, слот оружия, инвентарь, окно персонажа, Пип-Бой.
- **Сохранение/загрузка** (F5/F9, localStorage).

## Управление

| Действие | Клавиши |
|---|---|
| Идти / говорить / атаковать | ЛКМ |
| Прямое движение | WASD, стрелки |
| Камера | ПКМ (перетаскивание), Q/E, колесо |
| Инвентарь / Персонаж / Пип-Бой | I / C / P |
| Начать бой / конец хода | F / Пробел |
| Сохранить / загрузить | F5 / F9 |

## Структура

```
src/
  core/      математика, шум, игровые таймеры
  engine/    рендерер и пост-обработка, частицы, боевые эффекты
  world/     рельеф, текстуры, навигационная сетка (A*), наполнение мира
  entities/  процедурные модели с анимацией, актёры
  game/      S.P.E.C.I.A.L., предметы, бой, диалоги, задания, главный цикл
  ui/        интерфейс
```

Стек: TypeScript, Three.js, Vite.
