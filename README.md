# Пустошь 2241 — Арройо (3D)

Фанатское переосмысление Fallout 2 в полном 3D с современным рендером. Сейчас это вертикальный срез: стартовая локация Арройо с ключевыми механиками оригинала.
Ассеты оригинала не используются: вся графика процедурная (модели, текстуры, рельеф).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

## Что уже есть

- **Мир**: одиннадцать локаций (Арройо, Кламат, Дэн, Нью-Рино, Брокен-Хиллз, Убежище-Сити, Гекко, Убежище 13, Сан-Франциско, Наварро, платформа Анклава посреди океана). Проезжая рядом с неизвестным местом, ты отмечаешь его на карте и процедурные карты случайных встреч. Выход на карту мира — через зелёные зоны у края локации. На карте мира идут дни пути и случаются встречи с гекконами, крысами и бандитами.
- **Графика**: PBR-материалы, атмосферное небо, мягкие тени, туман, ACES-тонмаппинг, bloom, цветокоррекция, трава на ветру, частицы огня, дыма и пыли. Есть смена дня и ночи: солнце движется по небу, закат тёплый, ночь лунная со звёздами.
- **Модели**: процедурные скелетные модели (люди, гекконы, брамины, собаки, крысы) с анимациями через AnimationMixer: покой, ходьба, удары под каждый тип оружия, попадание, смерть. Надетая броня видна на модели.
- **Персонаж**: создание героя по S.P.E.C.I.A.L., семь навыков (включая Бартер), уровни и очки навыков.
- **Пошаговый бой**: очки действия, шанс попадания по навыку и КБ, порог и сопротивление урону, криты от Удачи, прицельные атаки по частям тела с увечьями. Компаньоны (пёс Дымок, Сулик) сражаются на твоей стороне.
- **Снаряжение**: копьё, нож, кувалда, самопал, 10-мм пистолет, охотничья винтовка, три вида брони, целебный порошок и стимуляторы.
- **Торговля**: обмен в духе Fallout у Хакунина, Мэйды и Бекки. Цены зависят от Бартера.
- **Сюжет в трёх главах**: «Поиски ГЭКК» (Арройо → Кламат → Дэн → Убежище-Сити → Гекко → Убежище 13) и «Анклав» (Сан-Франциско → Наварро → танкер «Посейдон» → платформа: освобождение племени, перегрузка реактора, бой с полковником, эвакуация на время) с эпилогом, который зависит от решений игрока. Побочные задания: «Гнездо в каньоне», «Пропавший Дымок», «Крысы на складе», «Утечка в Гекко», «Топливо для «Посейдона»».
- **Нью-Рино**: казино с костями (шанс зависит от Удачи), боксёрский ринг на кулаках (проигрыш — нокаут, а не смерть), вражда семей Морелли и Карвер с выбором стороны.
- **Брокен-Хиллз**: урановая шахта с радскорпионами и шериф-супермутант Маркус.
- **Отряд**: Дымок, Сулик, Кэссиди (дробовик), Маркус (пулемёт); спутникам можно приказать ждать в локации и позже забрать.
- **Способности**: на каждом нечётном уровне — одна из 13 (Ловкач, Скорострел, Меткий глаз, Толстокожий, Наблюдательность и др.).
- **Маскировка**: новобранец из Наварро в силовой броне сходит на платформе за своего, пока не поднимет тревогу. Турели можно перепрограммировать.
- **Океан**: вода с отражениями, побережья, пирсы и палубы на сваях.
- **Радиация**: радиоактивные зоны, счётчик Гейгера, лучевая болезнь (−ОД), Рад-Х и Антирадин, лечение у доктора.
- **Помещения**: Убежище 13 с отдельным освещением; разумные когти смерти, с которыми можно договориться (Красноречие, Наука, крышки) или драться.
- **Диалоги** с проверками навыков и особыми репликами при низком Интеллекте.
- **Звук**: всё синтезируется через Web Audio — ветер, костры, сверчки, шаги, удары, выстрелы, генеративная музыка для исследования и боя.
- **Сохранение/загрузка** (F5/F9).

## Управление

| Действие | Клавиши |
|---|---|
| Идти / говорить / атаковать | ЛКМ |
| Прямое движение | WASD, стрелки |
| Камера | ПКМ (перетаскивание), Q/E, колесо |
| Инвентарь / Персонаж / Пип-Бой | I / C / P |
| Начать бой / конец хода | F / Пробел |
| Прицельная атака | Shift+клик по врагу или кнопка «ПРИЦЕЛ» |
| Звук вкл/выкл | M |
| Сохранить / загрузить | F5 / F9 |

## Структура

```
src/
  core/      математика, шум, игровые таймеры
  engine/    рендерер и пост-обработка, частицы, боевые эффекты
  world/     рельеф, текстуры, навигационная сетка (A*), наполнение мира
  entities/  процедурные модели с анимацией, актёры
  game/      S.P.E.C.I.A.L., предметы, бой, диалоги, задания, главный цикл
  ui/        интерфейс
```

Стек: TypeScript, Three.js, Vite.
